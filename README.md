# Mitonne

Batch cooking de la semaine selon les promotions Migros, Coop, Denner, Aldi et Lidl : choix des plats, liste de courses, session minutée, frigo, congélateur et rappels de décongélation.

Site statique publié avec GitHub Pages. Les prix sont lus dans `data/actions.json`, mis à jour chaque lundi, jeudi et vendredi. Les réglages et la semaine restent dans le navigateur de chaque personne.
