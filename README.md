# Popote

Batch cooking de la semaine selon les promotions Migros, Coop, Denner, Aldi et Lidl.

Site statique : ouvrir `index.html` via un serveur web. Les prix sont lus dans `data/actions.json`, mis à jour chaque lundi, jeudi et vendredi. Les réglages et la semaine restent dans le navigateur de chaque personne.
